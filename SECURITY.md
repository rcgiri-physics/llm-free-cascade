# Security

This package handles your provider API keys, so reports are welcome, including
small ones such as a key appearing in a log or error message.

Please report a vulnerability privately through
[GitHub security advisories](https://github.com/rcgiri-physics/llm-free-cascade/security/advisories/new)
rather than in a public issue, and don't include real API keys.

This is a project maintained in spare time, so a reply may take a few days.
Only the latest published version gets fixes.
